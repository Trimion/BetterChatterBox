# BetterChatterBox (BCB) - Документация для разработчиков

## Обзор проекта

**BetterChatterBox (BCB)** - это расширение для браузера Chrome, предназначенное для автоматизации работы с внутренними системами Яндекс. Расширение помогает специалистам поддержки автоматизировать рутинные задачи и повысить эффективность работы.

**Версия:** 2.1.6.36  
**Лицензия:** GNU Affero General Public License v3.0 (AGPL-3.0)  
**Минимальная версия Chrome:** 118.0

## Карта модулей

### 1. Основные файлы

#### `manifest.json`
- **Назначение:** Конфигурация расширения (Manifest V3)
- **Ключевые секции:**
  - `action` - настройки всплывающего окна и иконок
  - `background` - Service Worker для фоновых процессов
  - `content_scripts` - скрипты, внедряемые в веб-страницы
  - `permissions` - разрешения расширения
  - `commands` - горячие клавиши
  - `declarative_net_request` - правила блокировки

#### `js/background.js` (2917 строк)
- **Назначение:** Service Worker - основная логика расширения
- **Основные функции:**
  - Управление жизненным циклом расширения
  - Обработка сообщений между компонентами
  - Управление настройками и хранилищем
  - Обработка горячих клавиш
  - Система логирования
  - Управление уведомлениями
  - Экспорт/импорт данных

#### `js/content.js` (1325 строк)
- **Назначение:** Content Script - внедряется в веб-страницы
- **Основные функции:**
  - Автоматический поиск при загрузке страницы
  - Применение настроек к интерфейсу
  - Интеграция с модулями
  - Обработка пользовательских действий
  - Логирование действий пользователя

## API и интерфейсы

### 1. Система сообщений
```javascript
// Отправка сообщения в background
chrome.runtime.sendMessage({
  action: "actionName",
  data: {...}
}, callback);

// Получение сообщения в background
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  // Обработка сообщения
});
```

### 2. Хранилище настроек
```javascript
// Сохранение настроек
chrome.storage.local.set({key: value});

// Загрузка настроек
chrome.storage.local.get(['key'], (result) => {
  // Обработка результата
});
```

### 3. Уведомления
```javascript
// Создание уведомления
chrome.notifications.create({
  type: 'basic',
  iconUrl: 'img/48.png',
  title: 'Заголовок',
  message: 'Сообщение'
});
```

## Процесс разработки

### 1. Добавление нового модуля
1. Создать файл в `js/modules/`
2. Использовать IIFE паттерн
3. Экспортировать функции через `window.ModuleName`
4. Добавить в `manifest.json` если необходимо
5. Обновить документацию

### 2. Добавление новой функции
1. Определить модуль для реализации
2. Добавить настройки в `settings.js`
3. Обновить UI в `options.html`
4. Добавить обработку в `background.js`
5. Протестировать функциональность

### 3. Отладка
- Включить логирование в настройках
- Использовать DevTools для background и content scripts
- Проверить консоль браузера
- Использовать `Utils.log()` для отладки
